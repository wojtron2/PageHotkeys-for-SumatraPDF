# PageHotkeys-for-SumatraPDF
Tool for control of SumatraPDF even from fullscreen applications. It needs SumatraPDF 3.5+ in order to work properly.

This project is an independent tool and is not affiliated with, endorsed by, or maintained by the SumatraPDF project. 
SumatraPDF is a separate open-source PDF reader available at https://www.sumatrapdfreader.org/.
